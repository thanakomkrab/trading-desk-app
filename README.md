# Trading Desk — เว็บจริง + Backend

หน้าเดิม (Artifact ใน Claude.ai) ยิง request ไปที่ Anthropic ตรงจากเบราว์เซอร์ ทำให้ใช้ฟีเจอร์ "ค้นเว็บ" (web search) ไม่ได้เต็มที่
โปรเจกต์นี้แก้ปัญหานั้นด้วยการเพิ่ม **backend ของตัวเอง** (server.js) ที่ถือกุญแจ API จริงไว้ ทำให้:

- **ข่าว** — เซิร์ฟเวอร์เรียก Claude พร้อมเปิดใช้ web search จริง (คีย์เต็มรูปแบบรองรับแน่นอน ไม่ผ่าน proxy จำกัดสิทธิ์เหมือนเดิม)
- **ราคา + กราฟแนวโน้ม** — ดึงจาก [Twelve Data](https://twelvedata.com) ซึ่งเป็นราคาตลาดจริง (รายชั่วโมง) ไม่ใช่การเดาจากข่าวอีกต่อไป
- **คีย์ API ทั้งหมดอยู่ที่เซิร์ฟเวอร์** ไม่หลุดไปที่เบราว์เซอร์ของผู้ใช้

## โครงสร้างไฟล์

```
trading-desk-app/
├── server.js          ← backend (Express) — เรียก Anthropic + Twelve Data
├── package.json
├── .env.example       ← แม่แบบไฟล์เก็บคีย์ (คัดลอกเป็น .env)
└── public/
    └── index.html     ← หน้าเว็บ (เดิมจาก Artifact ปรับให้เรียก backend แทน)
```

## ขั้นตอนรันบนเครื่องตัวเอง (ทดสอบก่อน deploy)

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ถ้ายังไม่มี)
2. เปิด terminal ในโฟลเดอร์นี้ แล้วรัน:
   ```
   npm install
   ```
3. สมัครขอคีย์ 2 ตัว (ฟรีทั้งคู่สำหรับเริ่มต้น):
   - Anthropic API key: https://console.anthropic.com/settings/keys
   - Twelve Data API key (แผนฟรี): https://twelvedata.com/pricing
4. คัดลอก `.env.example` เป็น `.env` แล้วใส่คีย์ที่ได้ลงไป:
   ```
   cp .env.example .env
   ```
5. รันเซิร์ฟเวอร์:
   ```
   npm start
   ```
6. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` — หน้าเว็บจะเหมือนเดิมทุกอย่าง แต่ตอนนี้ปุ่ม "ดึงข้อมูลล่าสุด" จะได้ราคาจริงและข่าวค้นจริง

## Deploy ให้ใช้งานได้จริงบนอินเทอร์เน็ต (แนะนำ Render — ฟรี เริ่มต้นง่าย)

1. สร้างบัญชีที่ https://render.com (ฟรี ล็อกอินด้วย GitHub ได้)
2. อัปโหลดโค้ดโฟลเดอร์นี้ขึ้น GitHub repo ของคุณ (ห้าม commit ไฟล์ `.env` ขึ้นไปเด็ดขาด — ใส่ `.env` ใน `.gitignore`)
3. ใน Render กด "New +" → "Web Service" → เลือก repo ที่อัปโหลดไว้
4. ตั้งค่า:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. ไปที่แท็บ "Environment" ของ service แล้วเพิ่มตัวแปร `ANTHROPIC_API_KEY` และ `TWELVE_DATA_API_KEY` (ค่าจริงของคุณ — ไม่ใช่ค่าตัวอย่าง)
6. กด Deploy — Render จะให้ URL สาธารณะมา (เช่น `https://your-app.onrender.com`) ที่เปิดจากมือถือหรือคอมไหนก็ได้

## ข้อควรรู้ / ข้อจำกัดที่ยังเหลืออยู่

- ราคาและกราฟเป็น**รายชั่วโมง** จาก Twelve Data ไม่ใช่ tick แบบวินาทีต่อวินาที — ถ้าต้องการระดับนั้นต้องอัปเกรดแผน Twelve Data หรือเปลี่ยนไปใช้ API ของโบรกเกอร์โดยตรง (เช่น OANDA, MetaTrader)
- แผนฟรีของ Twelve Data มีโควตาจำนวนครั้งต่อวัน ถ้าผู้ใช้กด "ดึงข้อมูลล่าสุด" บ่อยเกินไปอาจชนโควตา (โค้ดจะแสดง error ที่การ์ดให้เห็นชัดเจน)
- ผู้จัดการความเสี่ยงและเจ้าหน้าที่ส่งคำสั่งในหน้านี้**ยังเป็นแนวคิด ไม่ได้ต่อกับบัญชีเทรดจริง** — การต่อเข้ากับบัญชีจริงเพื่อส่งคำสั่งซื้อขายอัตโนมัติเป็นงานอีกขั้นที่ต้องระวังเรื่องความเสี่ยงทางการเงินอย่างมาก ควรมีมนุษย์ยืนยันก่อนส่งคำสั่งจริงเสมอ
